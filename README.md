# Фотоклуб «Объектив» — учебный проект

Полностью статический адаптивный сайт: HTML5 + CSS3 (19 модулей) + JavaScript (17 ES-модулей) + Bootstrap 5.
Никакого бэкенда, никакой сборки, никакого Python — только браузер.

## Структура

```
index.html              разметка + подключение всех модулей
css/                     19 файлов, один компонент/зона ответственности — один файл
js/                      17 ES-модулей (import/export), main.js — точка входа
assets/audio/            сгенерированный WAV для фонового плеера
tools/                   Node-скрипт, которым сгенерирован WAV (npm run generate:audio)
```

Подробное описание каждого модуля — в методическом пособии (глава 3 и 4).

## Почему нужен локальный сервер, а не просто открыть файл

`js/main.js` подключён как `<script type="module">` и использует `import`/`export`.
Браузеры по соображениям безопасности запрещают загрузку ES-модулей по протоколу
`file://` (двойной клик по `index.html` откроет страницу без стилей и без скриптов
с ошибкой CORS в консоли). Нужен настоящий HTTP-сервер — локально или после деплоя.

### Вариант 1 — WebStorm (проще всего)

Откройте папку проекта как проект WebStorm, откройте `index.html`, нажмите на иконку
браузера в правом верхнем углу редактора (или правый клик по файлу → *Open in Browser*).
WebStorm поднимет собственный встроенный сервер (обычно `http://localhost:63342/...`) —
ES-модули заработают сразу, ничего дополнительно ставить не нужно.

### Вариант 2 — через npm/Node (без WebStorm)

```bash
npm start
```

Это выполнит `npx serve . -l 5500` и поднимет сайт на `http://localhost:5500`
(при первом запуске `npx` один раз скачает пакет `serve` — интернет нужен только
для этого шага).

## Деплой на GitHub Pages

1. Создайте репозиторий на GitHub и запушьте проект:
   ```bash
   git init
   git add .
   git commit -m "Фотоклуб Объектив: учебный проект"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/<название-репозитория>.git
   git push -u origin main
   ```
2. В репозитории: **Settings → Pages → Build and deployment → Source**: `Deploy from a branch`.
3. **Branch**: `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу
   `https://<ваш-логин>.github.io/<название-репозитория>/`.

GitHub Pages отдаёт файлы по HTTPS — это тот самый «настоящий сервер», поэтому
ES-модули там работают без каких-либо дополнительных настроек. Файл `.nojekyll`
в корне уже отключает ненужную для статического сайта Jekyll-обработку.
Все пути в проекте относительные (`css/...`, `js/...`, `assets/...`), поэтому сайт
корректно откроется и в подпапке `username.github.io/repo-name/`, а не только в корне домена.

## Пересборка фонового звука

Если нужно изменить фоновый эмбиент-звук, отредактируйте параметры в
`tools/generate-ambient-audio.js` и выполните:

```bash
npm run generate:audio
```

Скрипт использует только встроенные модули Node.js (`fs`, `path`) — никаких
npm-зависимостей ни для сайта, ни для этого инструмента не требуется.
